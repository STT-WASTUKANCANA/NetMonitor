**NetMonitor** adalah solusi monitoring jaringan berbasis web yang dirancang untuk memantau status, performa, dan ketersediaan perangkat jaringan secara real-time. Sistem ini menyediakan antarmuka yang intuitif untuk mengelola dan memvisualisasikan data jaringan dengan mudah.

## 🌟 Fitur Unggulan

*   **Real-time Dashboard**: Visualisasi langsung status perangkat (UP/DOWN) dan metrik jaringan.
*   **Hierarchical Management**: Pengelolaan perangkat yang terstruktur dan mudah dinavigasi.
*   **Alert System**: Deteksi dini gangguan jaringan untuk respon yang lebih cepat.
*   **Performance Monitoring**: Analisis latensi dan stabilitas koneksi antar perangkat.
*   **Reporting**: Laporan terintegrasi untuk evaluasi performa jaringan.

## 🛠️ Teknologi

Sistem ini dibangun dengan stack teknologi modern yang efisien:

*   **Frontend**: Streamlit
*   **Backend**: FastAPI
*   **Database**: MySQL
*   **Engine**: Python Scripts
